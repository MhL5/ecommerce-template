# Progress

## Decisions
- Build command: the repo pins pnpm via `devEngines.packageManager` (`onFail: error`), so `npm run build` exits with `EBADDEVENGINES`. Every "npm run build" step is run as `pnpm build` (same `next build` script).
- Next.js 16.4 with `cacheComponents` + `typedRoutes`: catalog pages are server components over static mock data (prerendered); anything reading `searchParams` sits inside `<Suspense>`; product detail uses `generateStaticParams`.
- No backend: cart, session, registered users and orders live in `localStorage` through a small `useSyncExternalStore` store (`src/lib/createLocalStore.ts`). Pages that depend on them (cart, checkout, account, admin) are client components.
- Order confirmation is `/checkout/success?order=<id>` instead of a dynamic `[id]` route, because orders exist only in the browser and can't be prerendered.
- All route files were scaffolded as placeholders early (while building the product card) because `typedRoutes` rejects links to routes that do not exist yet; each page is filled in by its own task.
- Product images are generated SVGs (category icon on a gradient) in `public/products`, so the app needs no remote image hosts.
- Prices stored as integer cents in USD.
- ESLint forbids importing `next/link`/`next/image` directly, so thin `Link`/`Img` wrappers live in `src/components/ui`.
- UI uses only shadcn components (base-ui flavor, `base-vega` style, Hugeicons) and the tokens in `src/styles/globals.css`.
